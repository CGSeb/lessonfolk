---
name: edit-course
description: Add, revise or reorder lessons in an existing LessonFolk course, keeping lesson files, ids, course.yaml and prerequisites in sync, validated with check:courses. Use when the user wants to change a course that already exists (e.g. "add a lesson to…", "improve lesson…", "reorder the lessons of…").
---

Follow the "Edit a course" procedure in `AGENTS.md` (Contributing section). Read
`docs/course-format.md` first, warn the author before changing any lesson id, and write
nothing before they approve the proposed changes.
