name: create-course
description: Create a new Apprentice course with its author — interview, outline for approval, then course.yaml, lessons and the index.yaml entry, validated with check:courses. Use when the user wants to create, write or add a new course (e.g. "create a course about…", "new course on…").
---

Follow the "Create a course" procedure in `AGENTS.md` (Contributing section). Read
`docs/course-format.md` first, and write no file before the author approves the outline.

To change a course that already exists (add, revise or reorder lessons), use `edit-course` instead.
