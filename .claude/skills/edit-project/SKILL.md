---
name: edit-project
description: Revise an existing LessonFolk practice project (brief, milestones, coaching notes, review criteria) in both languages, warning before any change that would shift learners' saved progress, validated with check:courses. Use when the user wants to change a project that already exists (e.g. "improve the project…", "add a milestone to…").
---

Follow the "Edit a project" procedure in `docs/authoring/edit-project.md`. Read
`docs/project-format.md` and the project first, warn the author before renaming the file or
adding, removing or reordering milestones or review criteria (saved progress refers to them by
number), and write nothing before they approve the proposed changes.
